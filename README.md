# VOLT — спортивная одежда

Адаптивный учебный интернет-магазин спортивной одежды в чёрно-неоновом стиле. Сайт показывает каталог, карточки товаров, фильтрацию и демонстрационную корзину.

## Страницы
- `index.html` — главная страница, философия бренда, преимущества и избранные товары.
- `catalog.html` — каталог из шести товаров с фильтрами «Все», «Верх» и «Низ».
- `cart.html` — корзина с подсчётом суммы и удалением товаров.

## Технологии
HTML5, CSS3, JavaScript, Flexbox, CSS Grid, Media Queries, localStorage, Git, GitHub Pages.

## Запуск
Скачайте проект и откройте `index.html` в браузере. Для удобной локальной разработки можно открыть папку в VS Code и запустить Live Server.

## Git-этапы для практической работы
- `main` — первоначальная структура сайта.
- `feature/second-page` — страница каталога и навигация между страницами.
- `feature/responsive` — адаптивный дизайн для мобильных устройств, состояния наведения и фокусировки.
- Дополнительное улучшение: `cart.html` и `script.js` добавляют демонстрационную корзину и фильтры.
